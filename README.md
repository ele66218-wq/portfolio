# music_maker

## 概要
Canvas上に音符を配置し、配置した音を再生できる簡易音楽作成ツールです。

## 使用技術
- HTML
- CSS
- Javascript
- Canvas
- Web Audio API


## 機能
- Canvas上に音符を配置
- 音の高さと開始時刻を指定
- 配置した音符の再生
- 複数の音を組み合わせた再生
- 波形の種類の切り替え

## 工夫した点
- Math.sin などの基本的な式から音を生成しているため、音色を増やしやすい構造にしました。
- Canvasを使って、音の高さと時間を視覚的に配置できるようにしました。
- 音の開始時刻や長さをデータとして管理し、配置した音符をまとめて再生できるようにしました。
- 音が急に切れないように、時間とともに音量が小さくなる処理を入れました。

## 苦労した点
- Canvas上のクリック位置を、音の高さや開始時刻に変換する処理が難しかったです。
- Web Audio APIを使って音を鳴らす仕組みの理解に苦労しました。
- 音のデータは入っているのに音が鳴らないことがあり、原因の切り分けに時間がかかりました。

# calculator
## 概要
これは一般的な電卓ツールです。四則演算ができます。

## 使用技術
- HTML
- CSS
- Javascript

## 機能
- 四則演算
- %を用いた計算
- 計算履歴の表示
- 履歴の削除
- 不正な入力の防止

## 工夫した点
- 浮動小数点誤差による問題も修正してあります。(0.1+0.2=0.300...04になってしまうなど。)　小数第12位で四捨五入することにより解決しました。
- 3++3などは=を押してエラーになるようにはせずそもそも入力できないようにしています。
- `eval` を使わず、自分で文字列を分解して計算する処理を作りました。

## 苦労した点
- 入力された文字列を数値や演算子に分ける処理が難しかったです。
- 演算子の優先順位を考えて、掛け算・割り算を先に処理する部分に苦労しました。
- 小数計算で誤差が出る問題に気づき、表示上自然な結果になるよう調整しました。
